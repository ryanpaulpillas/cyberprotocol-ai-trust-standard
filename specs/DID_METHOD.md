# DID Method: did:cyber
**Version:** 1.0 — Draft
**Status:** Proposed
**Reference:** cyberprotocol.io
## Overview
The `did:cyber` DID method extends the W3C DID standard to support both human and AI agent identities, enabling verifiable provenance and compliance attestation across all jurisdictions.
## Syntax
`did:cyber:<method-specific-id>`
## Purpose
- Decentralized identity for AI agents
- Cryptographic binding between model, operator, and provenance
- Interoperable with W3C DID Core and Verifiable Credentials
