# Examples

Illustrative artifacts that document the **proposed** CyberProtocol data formats.
Values (keys, digests, proofs) are placeholders for documentation only.

| File | What it shows |
|------|---------------|
| [`did-agent.json`](did-agent.json) | A `did:cyber:agent` DID Document binding a signing key to a model, version, and operator |
| [`cyber-seal.json`](cyber-seal.json) | A `CyberSeal` certifying an output, with a Data Integrity proof and compliance metadata |
| [`compliance-metadata.json`](compliance-metadata.json) | A compliance object mapping one output to EU AI Act, NIST AI RMF, and ISO/IEC 42001 |

See the [specification](../spec/README.md) for field definitions and the verification algorithm.
